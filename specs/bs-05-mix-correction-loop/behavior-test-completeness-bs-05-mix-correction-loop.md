## Summary — ITEST-1 (harness scaffold)

Grade counts: **12×A, 0×B**.

Bs to fix: none.

Judgement calls:
- **Independence of `referenceDeltaE00` verified directly.** `correction_harness.dart` imports no product colour/mixing metric — not `lib/compare/difference.dart` (grepped: the only mention is the line-232 comment that correctly scopes the shipped metric as a *separate* thing). `referenceDeltaE00` is a complete standalone CIEDE2000 (G factor, `h'` averaging with wraparound, `R_T` hue-rotation), so AC-2 will grade the product `deltaE00` against an authority it provably cannot be. Externally validated against the five published Sharma/Wu/Dalal pairs (recomputed, all match to 1e-3) plus a self-distance-0 sanity guard — so the reference cannot silently be ΔE76/ΔE94. Note: `RECIPE_DEEP_OLIVE.deltaE00` is *built* from `referenceDeltaE00`, keeping the fixture self-consistent with the reference rather than the product metric — correct for a test fixture.
- **Fixture / scene math recomputed independently.** `SAMPLE_DEEP_OLIVE` (a=−1.2561, b=23.9671) → C = 23.99999, h = 93.00009°, both centred in the asserted `closeTo(24, 0.05)` / `closeTo(93, 0.1)` bands. All four scene guards hold as written: SCENE_OFF ΔE00 10.06 (>2), L exactly 6 below target, hue 114°>93° (toward green); SCENE_CLOSE 0.96 (≤2); SCENE_CLOSER 4.95 (between tolerance and SCENE_OFF); SCENE_OCHRE_TRACE b 18.5<23.97, ΔE00 2.81 (between tolerance and SCENE_OFF). Target olive (42, −1.2561, 23.9671) and tolerance 2.0 confirmed. Every guard assertion is TRUE for the fixtures as written, with margin.
- **Non-vacuity.** Both pending-gate loops are non-vacuous: test 1 loops the fixed range `n=1..10` and pins `length == 10`; test 2 carries its **own** `expect(pendingACs, isNotEmpty)` before its per-AC loop (an improvement over bs-04, where test 2 relied on the sibling test). The `RECIPE_DEEP_OLIVE` component loop and the five-paints check each assert `isNotEmpty` / an exact `length` before/alongside their loop, and the scenes guard is over four const-named scenes, not an emptiable collection. No loop can pass over an empty set.
- **Comments honest.** The harness header's claim that "the real engine … is exercised" is forward-looking doc for the ITEST-2/3 AC vocabulary, not a claim about what ITEST-1 asserts; ITEST-1 only boots + checks empty state + guards fixtures/reference, which matches what it checks. The scene comments' approximate ΔE00 figures match the recomputed distances. Minor (non-docking) note: the reused `FakeSpeech`/`FakeHaptics` doc comments cite "AC-8"/"AC-12" (carried from the bs-03/bs-04 shared fakes); the bs-05 consumers are AC-7 (speech) and the haptics seam — stale AC numbers in the shared fake files, not in the graded tests.
- **Determinism.** `pumpAndSettle` throughout `givenCorrection` and every `when…`; the gate's dual-mode assertions use the `forceRunPending` override rather than env/sleep. No fixed sleeps anywhere. `givenCorrection` pumps a `const SizedBox()` first to dispose any prior screen State so each scenario gets a fresh controller — deterministic across repeated opens.

Gate recommendation: **PASS** — the ITEST-1 harness scaffold meets the grade-A bar.
