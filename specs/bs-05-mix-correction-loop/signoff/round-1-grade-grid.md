# Behaviour-test completeness grid — bs-05-mix-correction-loop — SIGNOFF-1 fresh regrade, graded 2026-10-11 by an independent grader (fresh context), G1–G6 rubric

Graded in a fresh context by reading every test in `integration_test/correction_test.dart`
(smoke, both pending-gate tests, the 2 fakes, 5 fixtures, 2 reference tests, and the 10
`TestAC01..TestAC10`) together with the product code each one exercises
(`lib/correction/**` — controller, engine, words, speech, regions, read endpoint;
`lib/compare/difference.dart`; `lib/readout/provenance_region.dart`/`readout_screen.dart`;
`lib/app/build_app.dart`; `lib/app/router.dart`; `lib/capture/**`; and the
`FakeCaptureSource`/`SoftwareCaptureSource` capture path). Assertions were traced against
what the code actually produces, not against comments.

The device suite was **not** run (another process holds the device lock); grading is by
code reading and independent recomputation. The load-bearing geometry was recomputed with a
standalone CIEDE2000 (reproducing all five Sharma/Wu/Dalal 2005 published pairs to 1e-3):
SCENE_OFF ΔE00 **10.06** (>2; L exactly 6 below target; mixed hue 114° > target 93° → toward
green), SCENE_CLOSE **0.956** (≤2), SCENE_CLOSER **4.95** (<SCENE_OFF, >2), SCENE_OCHRE_TRACE
**2.81** (>2, <SCENE_OFF; b 18.5 < target 23.97), target C **24.000** / h **93.000**, and
`hueFamilyWord(114°) = 'green'`. Note: the shipped `deltaE00` (`lib/compare/difference.dart`)
and the test `referenceDeltaE00` are the same CIEDE2000 algorithm in separate source; the
reference is validated against published Sharma data by the reference guard, so a swapped-in
wrong shipped metric (CIE76/CIE94/R_T sign slip) would still be caught — G5 holds. The
measured swatch coordinates are the scene ground truth round-tripped through the software
source's Lab→sRGB→Lab feed, so the AC tests compare the shipped ΔE00 and the reference over
the *same* round-tripped swatch and use `closeTo`/magnitude guards rather than exact scene
numbers; AC-3's "by N" and the engine's value reading are computed from that same swatch, so
they never drift.
