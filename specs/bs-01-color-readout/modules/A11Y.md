## Interface reconciliation

- **`Speech`**: `speak(String utterance)`; one injected instance app-wide; consistent phrasing lives here, not
  in each screen (bs-08 extends it). The production impl wraps platform TTS; ITEST injects `FakeSpeech` that
  records utterances.
- **`Haptics`**: `confirm()` (a landing pulse) and any later patterns; production wraps the platform vibrator;
  ITEST injects `FakeHaptics` recording pulses.
- **Label-contract widgets:** `ColorChip` always takes text (no bare colour), `ProvenanceBadge` renders a tier
  label (+ note), `ValueReading` renders a number with its word. These enforce "no meaning in colour alone"
  structurally (SI Accessibility).

  READOUT-* phases; run serially.)*
- **Tasks:**
  1. AC-8: the speak action builds the utterance from `ColorScience.decompose(sample)` and calls `Speech.speak`
     once, containing name, value, temperature word, hue in words, chroma, hue angle.
  2. AC-12: on a just-captured sample, the controller fires `Haptics.confirm()` when the readout renders and
     sets the just-captured marker; `acknowledge()` clears it. A non-fresh readout fires neither.
  3. Unit-test the utterance composition and the just-captured state machine (every branch).
- **Exit criteria:** unit + coverage on touched files; grade gate.
- **Acceptance gate:** un-pend AC-8 and AC-12; `BS01_RUN_PENDING=1 flutter test integration_test/` green for
