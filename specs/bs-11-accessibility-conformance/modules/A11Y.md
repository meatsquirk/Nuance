## Interface reconciliation

- `AppTheme.light()` / `AppTheme.dark()` expose a WCAG 2.2 AA `ColorScheme` + `TextTheme` + a `ThemeData` with a 48dp `MaterialTapTargetSize`; `buildApp` consumes it in place of the inline `ThemeData(useMaterial3:true)` (`build_app.dart:233`). Feature screens stop hardcoding colours and read `Theme.of(context).colorScheme`.
- `StatusBadge({required String label, IconData? icon, Color? color})` — joins `ColorChip` under the existing label-contract pattern (`Semantics(label:…, excludeSemantics:true)`); `color` is decorative only, `label` required non-empty (assert).
- `AccessibleNotice` — a notice surface that never auto-dismisses (no `Duration` timer); dismissed only by an explicit control. Replaces any `SnackBar`/toast that would auto-dismiss.
- The per-rule check **rules** live in `integration_test/conformance/checks/<rule>.dart`, each a function `ConformanceRuleOutcome check<Rule>(WidgetTester, Finder)` consumed by GATE's aggregate `runConformanceCheck`. A11Y phases author the rule beside the compliance fix so each AC test asserts both sides.
- Spec vs architecture: the SI names shared widgets + two gates; the spec's "every screen" is reconciled by D-1 (sweep screens on `main` at branch; later features self-gate).
