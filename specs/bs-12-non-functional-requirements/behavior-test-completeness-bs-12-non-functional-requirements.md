## Verdict

**15 A / 0 B — PASS (all A).**

All fifteen tests (five flow-launch smokes + ten guard/scaffold/fake tests) meet the scaffold bar. The phase is genuinely non-vacuous where it counts: the two highest-risk scaffold tests — the authority-config guard and the pending-gate map — do not rely on trivially-passing `isEmpty` checks but pin exact contents, sizes and ownership, so they fail a blank or mis-seeded shell. The flow smokes discriminate per-flow by asserting five *distinct* real home-screen types against `buildApp`'s real entry precedence, and the accuracy test grades with a verified independent CIEDE2000 (`comparison_harness.dart:161` region), not the product metric against itself, so "no colour math faked" (D-7) holds. Everything is deterministic (`pumpAndSettle` / async `Stopwatch`, no fixed sleeps), and every comment claims only what its code checks — the stub-era claims ("GUARD-2 sink is inert", "ITEST-1 only proves the real app assembles") are honest about what later phases still wire.

Two rows are the weakest but still pass at A: the swap-harness smoke (modest discrimination — asserts assembly, not caller routing, but the comment scopes the claim) and the gate-skip loop (its non-vacuousness is backstopped by the sibling count test rather than an in-test size guard). Neither crosses into B. No changes required before ITEST-2/3.
