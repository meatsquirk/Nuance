## Summary — ITEST-1 (harness scaffold)

Grade counts: **11×A, 0×B**.

Bs to fix: none.

Judgement calls:
- **Independence of `referenceDeltaE00` verified directly.** `recipes_harness.dart` imports no product colour/mixing math — not `compare/difference.dart`; its only reference to that path is the line-217 comment that correctly scopes the shipped metric as a *separate* thing. `referenceDeltaE00` is a complete standalone CIEDE2000 (G factor, `h'` averaging with wraparound, `R_T`), so AC-5 will grade the product `deltaE00` against an authority it provably cannot be. Externally validated against five published Sharma/Wu/Dalal pairs (recomputed, all match to 1e-3) plus a self-distance-0 sanity guard — so the reference cannot silently be ΔE76/ΔE94.
- **Fixture math recomputed independently.** `SAMPLE_DEEP_OLIVE` (a=−8.65, b=26.63) → C = 27.99963, h = 107.99492°, both well inside the asserted `closeTo(28, 0.05)` / `closeTo(108, 0.1)` bands. Out-of-gamut control: turquoise a=−38 (< −20 ✓), chroma = 40.4969 (> 35 ✓), and every "My paints" masstone a\* (−0.5 / 12 / 0 / 18 / 32) is > −5 ✓ — so the palette is geometrically incapable of reaching a strongly-green target, a genuine control rather than a labelled one. `PALETTE_OIL` is all oil ✓. All guard thresholds hold with margin.
- **Pending gate test 2 graded A despite its per-AC loop over `pendingACs.keys` not carrying its own size guard.** It is not vacuous here: the sibling test pins `pendingACs.length == 12`, and the `AC-unmapped` / ambient-path assertions in the same test execute regardless of map contents (true either way, rule 1). If the two gate tests were ever split across files, test 2 should gain its own `expect(pendingACs, isNotEmpty)` — noted, not docked. The `PALETTE_MY_PAINTS` loop in the turquoise guard is likewise un-guarded for emptiness, but a compile-time const palette cannot dynamically empty and the sibling "five paints" test pins `length == 5`; no dock.
- **Comments are honest.** The harness header's claim that "the real engine … is exercised" is forward-looking doc for the ITEST-2/3 AC vocabulary, not a claim about what ITEST-1 asserts; ITEST-1 only boots + checks empty state + guards fixtures/reference, which matches what it checks. The out-of-gamut and "AC-3 names three" comments both scope themselves accurately and defer the engine behaviour to the owning phases.
- **Determinism.** `pumpAndSettle` throughout `givenRecipes` and every `when…`; the gate's dual-mode assertions use the `forceRunPending` override rather than env/sleep. No fixed sleeps anywhere.

Gate recommendation: **PASS** — the ITEST-1 harness scaffold meets the grade-A bar.
